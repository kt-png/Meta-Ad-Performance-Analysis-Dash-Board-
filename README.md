# 📊 Meta Ads Performance Analysis Dashboard | Power BI

## 📌 Project Overview

This project focuses on analyzing Meta advertising campaign performance across Facebook and Instagram using Microsoft Power BI.

The objective is to evaluate advertising effectiveness, understand audience engagement, monitor campaign performance, and identify opportunities to improve marketing strategies through interactive dashboards and data-driven insights.

The dashboard provides a comprehensive view of advertising performance through KPI tracking, demographic analysis, geographic visualization, and time-based trend analysis.

## 🎯 Project Objectives

- Analyze overall advertising campaign performance.
- Monitor impressions, clicks, and engagement.
- Evaluate conversion rates and campaign effectiveness.
- Understand audience demographics.
- Analyze geographic advertising performance.
- Identify peak engagement hours.
- Evaluate advertising budget utilization.
- Support data-driven marketing decisions.

## 📊 Key Performance Indicators (KPIs)

The dashboard tracks six important advertising metrics:

| KPI | Description |
|---|---|
| Impressions | Total number of times advertisements were displayed |
| Clicks | Total number of clicks received |
| Click-Through Rate (CTR) | Percentage of impressions resulting in clicks |
| Engagement Rate | Percentage of impressions resulting in engagement |
| Conversion Rate | Percentage of clicks resulting in conversions |
| Budget Utilization | Percentage of allocated advertising budget utilized |
